iSyncX English

iTunes のライブラリを、
Android でも。

WindowsのiTunes内にある音楽、プレイリストなどをAndroidデバイスにWi-Fi経由で同期できます。

300 曲までは無料。もっと多くの曲を同期したい場合は、アプリの中で一度だけ購入してください（サブスクではなく買い切りです）。

できること

曲とプレイリストを転送

任意のプレイリスト、または「全曲」を Wi-Fi で転送します。途中で切断しても続きから再開できます。プレイリストは .m3u形式 でも保存するので、さまざまなプレーヤーアプリで使えます。

再生回数なども iTunes に

ただ曲を同期するだけでなく、Android のプレーヤー側で再生した回数や最後に再生した日、プレイリストへの追加も記録し、iTunes 側に反映できます。

レート(評価)も反映

Android のプレーヤーで付けたレート(評価)も iTunes 側に反映できます。iSyncX アプリの再生中画面やデバイスの通知欄から評価を付けられます。Poweramp と PlayerPro なら、アプリ内の評価機能と連動も可能です。

聴きながら、プレイリストに追加

気に入った曲は、iSyncX アプリの再生中画面から、iTunes のプレイリストにそのまま追加できます。Android のプレイリストにはすぐに入り、次の同期で PC の iTunes のプレイリストにも反映されます。PC の前に戻らなくても、聴きながらライブラリを整理できます。

iTunes のライブラリを守る安心設計

操作ミスでレート(評価)を付けても大丈夫。iTunes に反映したレート(評価)は、Androidアプリ側で 1 件ずつロールバック(無かったこと)できます。プレイリストへの追加も同じように取り消せます。書き込む日の最初には、iTunes のライブラリを自動でバックアップします。

クラウドもアカウントも不要

データが行き来するのは、同じ Wi-Fi 環境にある、あなたの PC と Android の間だけです。

PC の曲は消さない

iSyncX が PC に保存された曲やプレイリスト、iTunes のライブラリを削除することはありません(プレイリストへの追加を取り消したときに外すのは、iSyncX から追加したその 1 曲だけです)。

入手する

PC と Android の両方に iSyncX を入れて使います。

Windows 用(無料)

PC で iTunes のライブラリを Android に渡すアプリです。タスクトレイに常駐します。

Microsoft Store で入手

Microsoft Store から入れると、更新も自動で届きます。Windows 用 iTunes(従来型)が必要です(下の項目を参照)。

Android 用

同期の操作、星の付与、再生の記録をするアプリです。

Google Play で入手

動作環境

PCWindows 10(1809 以降)または Windows 11、64 ビット。Mac には対応していません。
iTunesWindows 用 iTunes(64 ビット版)。Apple のダウンロードページ(apple.com/jp/itunes)の「ほかのバージョンをお探しですか?」から入手できます。
Microsoft Store 版の iTunes、Apple Music アプリ、Apple Devices アプリでは同期できません。
AndroidAndroid 8.0 以降
ネットワークPC と Android が同じ Wi-Fi につながっていること。Windows のネットワークの種類は「プライベート」にしてください。もし PC が有線ネットワークなどにつながっている場合、 Windows の「モバイル ホットスポット」機能をオンにし、その Wi-Fi にAndroidから接続すれば、同期できます。
音楽プレーヤーお好きなものを使えます。推奨は Poweramp(再生回数・評価・プレイリストが最も安定して連動します)。

はじめかた

  1. Windows 用 iTunes(64 ビット版) が導入された PC に、Windows 用の iSyncX を入れます。
  2. PC の iSyncX のウィンドウで「Androidデバイスを登録する」を押し、表示された QR コードを Android にインストールした iSyncX アプリの「QR コードで登録」で読み取ります。
  3. Android の「同期」タブで、曲の保存先のフォルダを選びます。
  4. 「同期する曲」タブで、「全曲」または同期するプレイリストを選びます。
  5. 「同期」タブで「同期する」を押します。
  6. 「再生中」タブで「許可する」を押し、通知へのアクセスを許可します(聴いた回数を記録するのに必要です)。

PC の iSyncX は自動では起動しません。同期するときは、PC で iSyncX を起動しておいてください。

聴いている曲をプレイリストに追加する

  1. お好きなプレーヤーで曲を再生します。
  2. iSyncX の「再生中」タブで「プレイリストに追加」を押します。
  3. 追加先のプレイリストを選びます。Android に同期しているプレイリストなら、その場で Android のプレイリストにも入ります。
  4. 次に「同期する」を押すと、PC の iTunes のプレイリストにも追加されます。

間違えて追加したときは、すぐに出る「取り消す」か、履歴から取り消せます。追加先に選べるのは、iTunes で自分で作ったプレイリストです(スマートプレイリストには追加できません)。PC と Android の両方の iSyncX が 1.1.0 以降である必要があります。
